# Кафе Бар Че

Responsive one-page website for Кафе Бар Че in Skopje, published with GitHub Pages.

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Content

- Google reviews and embedded Google map
- Instagram, Facebook, phone and email links
- Cafe/Bar structured data
- Responsive navigation and live opening-status indicator for Europe/Skopje

Brand assets are supplied by Кафе Бар Че. Initial venue photography is sourced from the business's public Tripadvisor listing and should be replaced with the original business files before final commercial launch.
